# FIRI Unlocker

Русский • [English](/README.md)

**FIRI Unlocker** — портативная утилита восстановления Windows, распространяемая в виде одного
статического исполняемого файла. Объединяет поиск точек закрепления в системе, инспекцию процессов
и файлов и восстановление системы в одном инструменте; работает как в обычном сеансе, так и
в Safe Mode / WinPE / WinRE и не требует установки.

> [!CAUTION]
> Microsoft Defender и другие антивирусы могут помечать FIRI Unlocker как вредоносный.
> Это ложное срабатывание: инструмент обращается к системным файлам (читает, заменяет, редактирует),
> завершает процессы, изменяет значения реестра и всегда работает с правами администратора — такое
> поведение эвристические движки считают подозрительным. **FIRI Unlocker — это не вирус.**
> Код полностью открыт: каждый может просмотреть, проверить, изменить и собрать любой инструмент
> FIRI Project самостоятельно. Оригинальные подписанные сборки всегда доступны на странице
> [GitHub Releases](../../releases).

## Возможности

- Сканер персистенции по ~25 местам автозагрузки (64-битное и WOW64 представления реестра) с проверкой
  подписи Authenticode + каталогов для каждого упомянутого бинарника (`[signed]` / `[UNSIGNED]` /
  `[BAD-SIG]` / `[missing]`)
- Управляемый режим очистки, демон-страж IFEO-перехватов, интерактивный мастер триажа с постоянными
  вердиктами
- Работа с процессами: список, завершение по PID/имени, дерево родитель→потомок
- Разблокировка файлов через перечисление таблицы описателей ядра («какой процесс держит файл?»)
- Таблица TCP/UDP с именами процессов-владельцев
- Сканер альтернативных потоков NTFS («горячие» папки или указанный путь)
- Монтирование раздела EFI и аудит подписей
- Демон наблюдения за буфером обмена
- Восстановление системных файлов из WinSxS, починка шрифтов, возврат UAC, снятие блокировок политик
  Explorer/CMD
- Снимки автозагрузки и настройки хранятся внутри самого исполняемого файла (без реестра и внешних
  файлов)
- Система модулей: сторонние модули FIRI Unlocker (`.firiumodule`) встраиваются в исполняемый файл
  и выполняются в памяти, с проверкой таблицы импорта на доступ к реестру/файлам/сети и режимом
  разработчика для модулей с опасными возможностями
- Развёртывание одним файлом: статический CRT, встроенный манифест администратора, работа офлайн

## Сборка

Требования: Visual Studio Build Tools 2022 или новее (MSVC v143+, Windows SDK 10), командная строка
x64 Native Tools.

Компиляция:

```bat
cl /nologo /W4 /EHsc /O2 /MT /D_UNICODE /DUNICODE /Foobj\ /Febin\firiu.exe src\*.cpp ^
   /link /SUBSYSTEM:CONSOLE ^
   /MANIFEST:EMBED "/MANIFESTUAC:level='requireAdministrator' uiAccess='false'" ^
   user32.lib advapi32.lib shell32.lib gdi32.lib cfgmgr32.lib ^
   ole32.lib oleaut32.lib uuid.lib wintrust.lib iphlpapi.lib crypt32.lib
```

Каталог `obj\` — промежуточный вывод компилятора, после компоновки его можно удалить.

### Подпись кода (опционально)

Положите `FIRI_Project.pfx` в корень репозитория и подпишите собранный бинарник:

```bat
signtool sign /fd SHA256 /f FIRI_Project.pfx /p <пароль сертификата> bin\firiu.exe
```

Подпись убирает предупреждение SmartScreen на машинах конечных пользователей при доверии к сертификату.
При первом запуске программа предложит установить свой сертификат в хранилища доверия Local Machine
(Trusted Publishers и Trusted Root); запрос появляется только в классической Windows, не в WinPE/WinRE.

## Структура репозитория

```
firiu/
├─ src/
│  ├─ main.cpp              точка входа, разбор CLI, меню
│  ├─ common.cpp/.h         консольная основа, цвета, определение режима загрузки
│  ├─ autoruns.cpp/.h       исчерпывающий сканер автозагрузки
│  ├─ repairs.cpp/.h        снятие IFEO-перехватов и ограничений политик
│  ├─ watchdog.cpp          демон слежения за изменениями IFEO
│  ├─ triage.cpp/.h         хранение вердиктов + мастер триажа
│  ├─ snapshots.cpp/.h      снимки автозагрузки (ресурс внутри exe)
│  ├─ procs.cpp/.h          процессы: список, завершение, дерево
│  ├─ handles.cpp/.h        охотник за описателями ядра
│  ├─ net.cpp/.h            таблица TCP/UDP по процессам
│  ├─ ads.cpp/.h            сканер альтернативных потоков
│  ├─ efi.cpp/.h            проверка раздела EFI
│  ├─ cert.cpp/.h           предложение установки сертификата
│  ├─ sig.cpp/.h            проверка Authenticode + каталогов
│  ├─ firi_api.h            поверхность API для сторонних модулей
│  ├─ modules.cpp/.h        загрузчик модулей: in-memory PE, FIRIMETA, меню модулей
│  ├─ filerestore.cpp/.h    сверка системных файлов с WinSxS
│  ├─ quickfixes.cpp/.h     шрифты, UAC, интеграция в оболочку
│  ├─ hwinfo.cpp/.h         сводка по железу
│  ├─ unlock.cpp/.h         разрешение блокировок файлов
│  ├─ clip.cpp/.h           сторож буфера обмена
│  ├─ cfg.cpp/.h            самодостаточная конфигурация
│  └─ ui.cpp/.h             отрисовка TUI-меню
├─ README.md
├─ README_ru.md
└─ .gitignore
```

## Отказ от ответственности

FIRI Unlocker изменяет работающую систему. Используйте его только если понимаете, что делает каждое
действие. Программа поставляется «как есть», без каких-либо гарантий.
